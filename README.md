# Project 6: Advanced Numeric Pattern Generator

## Problem Description
This project generates a hollow diamond-shaped numerical pattern based on the size entered by the user. It validates the given dimension and displays a symmetric pattern with proper spacing and alignment.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Nested for loops
- Conditional statements (if, else)
- Arithmetic operators
- Pattern generation
- User input and output

## Files Included
- `Question_06_Numeric_Pattern.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the diamond size between 2 and 10.
5. View the generated hollow diamond pattern.

## Conclusion
The program generates a symmetric hollow diamond numerical pattern using nested loops and validates the input dimension to ensure correct pattern generation.
